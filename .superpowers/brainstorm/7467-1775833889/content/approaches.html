Three Approaches — Which fits best?

Pick the one that feels right. My recommendation is highlighted.

A

WordPress + WooCommerce

What it is: A CMS with e-commerce plugins on top.

Pros

  • Fast initial setup
  • Large plugin ecosystem
  • Built-in admin UI
  • Non-dev friendly for day-to-day

Cons

  • PHP — harder to customise deeply
  • WooCommerce is heavy for a no-payment store
  • Client area needs extra plugins
  • Plugin conflicts & security maintenance
  • Future payment integration = fighting WooCommerce

Effort: Low upfront · Risk: Medium (plugin debt)

RECOMMENDED
B

Custom Full-Stack App (Next.js + PostgreSQL)

What it is: A modern React frontend with API routes, a real database, and built-in auth — all in one codebase.

Pros

  • Full control over every feature
  • TypeScript end-to-end — safe & maintainable
  • Clean client + admin areas from day one
  • Adding payments later is straightforward (Stripe)
  • No plugin bloat — only what you build
  • Scales well as catalog grows

Cons

  • More upfront work than WordPress
  • You build the admin UI yourself

Effort: Medium · Risk: Low · Future-proof: High

C

Next.js Frontend + Headless CMS (Sanity / Strapi)

What it is: Custom React frontend but product & content managed via a dedicated CMS admin panel.

Pros

  • CMS admin UI comes mostly for free
  • Modern frontend stack
  • Good for content-heavy stores

Cons

  • Two systems to maintain
  • CMS pricing at scale
  • Client area still needs custom auth
  • Overkill for under 50 products

Effort: Medium · Risk: Medium (third-party dependency)

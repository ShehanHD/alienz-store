Auth (custom JWT in FastAPI)

  • Registration/Login — FastAPI hashes password with bcrypt, issues access + refresh JWT tokens
  • Access token — short-lived (15 min), sent in Authorization header
  • Refresh token — long-lived (7 days), stored in httpOnly cookie
  • Roles — client or admin, stored in DB and embedded in JWT
  • Portable — zero dependency on Supabase Auth; swap DB anytime

Image Upload Flow

  • Admin uploads image → FastAPI receives file
  • Pillow resizes to max 1200px width, converts to WebP, compresses
  • Thumbnail (300×300) also generated for product listings
  • Both uploaded to Supabase Storage — URL saved to DB

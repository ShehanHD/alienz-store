Why Railway over Vercel for FastAPI?

  • Vercel runs Python as short-lived serverless functions — 10s timeout, cold starts, no persistent connections
  • Railway runs FastAPI as a real persistent server — better for DB connections, background tasks, future payments
  • Railway free tier: $5 credit/month (enough for a small app)

Auth Flow

  • Supabase Auth handles sign-up, login, password reset, sessions
  • Frontend gets a JWT from Supabase on login
  • FastAPI validates the JWT on protected routes (no custom auth code needed)
  • Admin role = a flag on the user record in Supabase
